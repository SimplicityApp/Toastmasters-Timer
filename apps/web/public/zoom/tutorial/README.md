# Homepage tutorial screenshots

Drop PNGs here with these exact names. The homepage picks them up with no code
change. Any file that is missing shows a dashed placeholder box instead of a
broken image, so partial uploads are fine.

Capture everything inside the Zoom app so the screenshots match what people see.

## Steps (16:9 works best, roughly 1200x675)

| File | What it should show |
| --- | --- |
| `01-open-in-meeting.png` | A Zoom meeting with the Apps panel open and the timer inside it |
| `02-agenda-import.png` | Agenda tab with the import box, plus a filled agenda |
| `03-mode-menu.png` | Live tab with the display mode menu open, all three modes visible |
| `04-live-controls.png` | Live tab mid speech, timer running, green signal up |
| `05-report.png` | Report tab with a few finished speeches and the copy button |

## Display modes

## Tips

| File | What it should show |
| --- | --- |

Notes:

- Crop out anything personal: real names, real meeting IDs, other participants.
- Keep the three mode shots at the same size so the row lines up.
- The step shots sit next to text at about half the page width, so make sure
  any label you want people to read is still legible when scaled down.
